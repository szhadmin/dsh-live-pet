live 模式怎么用
  1. 把要接的直播间地址（开播中）填到上面，例如 https://live.douyin.com/123456789。
  2. 点「启动数据源」，服务端会自己拿 ttwid、算 signature / a_bogus、连抖音的弹幕 WebSocket， 解 protobuf，把聊天 / 礼物 / 进场 / 点赞 / 关注 转成本项目事件。
  3. 断线自动重连；状态里能看到「已连接 / 收到消息 N 条 / 最近一条」。

bridge / webhook 是给「已经有自己的弹幕监听器」的人用的，事件格式：

{"kind":"comment","username":"观众","text":"你好","event_id":"唯一ID"}
{"kind":"gift","username":"观众","gift":"小心心","count":1}
{"kind":"follow","username":"观众"}
